Overview

CultureHR is a Yii 2 Advanced Template application for human resources, school operations, finance, learning management, and employee self-service. The main application runs on the frontend app; shared business logic lives in common/modules.

Access: role = employee. HR users with linked employee records can switch via /site/employee-portal.

Portal
